# CSS Effects

## 示例：Gradient + Glass Card
- 关键词：`glassmorphism card css`（可在 CodePen 搜索）
- 技术：`linear-gradient()`、`backdrop-filter: blur()`、透明边框
- 用途：产品首页、弹窗、HUD面板
- 实现：背景叠加渐变；卡片半透明、模糊、细描边
- 限制：部分设备上模糊效果耗性能；移动端测试
- 状态：未尝试

## 示例：Hover Card
- 技术：`transform`、`transition`、阴影
- 用途：功能卡片、列表选择
- 实现：hover轻微上移、阴影增强；150–250ms
- 限制：移动端无hover，需点击反馈
- 状态：未尝试
