# Coding Prompts
## 示例：按现有项目实现功能
```text
先阅读项目结构和相关文件，不要立即修改。总结现状与目标差距，提出最小修改计划。实现时只改任务相关文件，保持接口兼容，补充必要错误处理。不要虚构测试结果。完成后列出改动文件、关键实现、运行/测试命令及未解决问题。
```
## 示例：证据驱动调试
```text
先复现问题。区分事实、推测和待验证假设。提出可能原因及验证步骤，优先最小实验，不要无证据地大范围修改。每次改动后说明验证结果；未运行测试需明确标注。
```
