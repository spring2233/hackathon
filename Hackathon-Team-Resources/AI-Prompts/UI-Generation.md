# UI Generation Prompts
## 示例：现代产品Landing Page
工具：Cursor、Claude、ChatGPT等代码助手
```text
Build a polished responsive landing page for [product]. Inspect the existing project first and reuse its framework and conventions. Visual direction: [style keywords], strong typography, clear spacing, restrained colors, subtle motion and accessible contrast. Sections: hero, value proposition, feature cards, demo and CTA. Use reusable components. Keep animations lightweight and responsive. Do not rewrite unrelated files. After implementation, list changed files and how to run it.
```
使用：替换产品、风格、页面模块和技术限制；先生成单页再迭代。
