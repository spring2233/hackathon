# Hackathon Team Resources

共享资源库：网页效果、UI参考、AI提示词、工具与素材。

## 目录
- `Web-Effects/` CSS、JS动画、WebGL/Three.js
- `UI-References/` Landing Page、Dashboard
- `AI-Prompts/` UI生成、编码、动画提示词
- `Tools/` AI开发工具
- `Assets/` 图片、音频、模型等素材

## 贡献规则
1. 新增前先搜索，避免重复。
2. 记录来源、用途、实现方法、限制和状态。
3. 状态：未尝试 / 尝试中 / 已验证 / 不推荐。
4. 大文件放共享云盘，仓库保存链接与说明。
5. 尊重许可、版权及署名要求。
